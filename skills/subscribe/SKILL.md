# Subscribe to Channel

Subscribe this session to a channel for group messaging.

## Arguments

- First argument: channel name (e.g. "deploys", "dashboard-team")

## Steps

1. Use the `subscribe` MCP tool with:
   - `channel`: channel name from first argument

2. Display confirmation: "Subscribed to CHANNEL."
