# Unsubscribe from Channel

Remove this session from a channel.

## Arguments

- First argument: channel name

## Steps

1. Use the `unsubscribe` MCP tool with:
   - `channel`: channel name from first argument

2. Display confirmation: "Unsubscribed from CHANNEL."
