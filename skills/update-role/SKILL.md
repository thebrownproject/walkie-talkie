# Update Role

Update this session's role description without re-registering.

## Arguments

- All arguments: the new role description

## Steps

1. Use the `update_role` MCP tool with:
   - `role`: new role description from arguments

2. Display confirmation: "Role updated to: NEW_ROLE"
